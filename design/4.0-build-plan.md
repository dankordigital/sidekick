# Sidekick 4.0: the build plan

The owner asked for 4.0 on 14 Nov 2026: **the app should look and move like
the prototypes** (the emulator, `design/emulator/`, built from the owner's
Figma design in `design/figma/`), with animations as smooth as the website's,
then **released to GitHub Releases with screenshots of the real app** sent to
the owner. Work through the phases in order. **Each phase ends green**
(`flutter analyze` clean, `flutter test` passing), committed and pushed, so
work can stop at any phase boundary and pick up again. Tick the boxes here as
phases finish (this file is the progress record; HISTORY.md gets a line per
phase).

## References (read before each phase)

- **Behaviour and exact look:** `design/emulator/emulator.src.html` (CSS tokens
  at the top: #121212 page, #1c1c1c panels, #262626 raised, white pills
  #f0f0f0 / #141414, amber #ffc56b on #2f2410 for "needs you", ok #45d07e,
  blue #5b9dff, green #4fcf86, orange #ffb84d, red #ff6b5e; Inter). Its
  screenshots: `design/emulator/shots/` (run `node check.js` to refresh).
- **The owner's Figma screens:** `design/figma/prototype/` (phone 390×844,
  computer 1280×800) and `design/figma/styles-and-components/`.
- **The 4.0 decisions in CLAUDE.md:** one look only (Nothing, Liquid Glass and
  Make theme go), the floating dock, Chat per device ("not a messaging app"),
  no badges or dots, hold a card for its actions (✕ or flick down closes),
  Copy code only for 6-digit codes, notices one at a time, verification codes
  only from phone notifications, choose your app icon (8 icons, Dusk default).
- **Motion like index.html:** springs and eased values, never jumps: press
  scale with a springy release, cards rising in, sheets that follow the
  finger, the sending ring easing, `Hero` between a card and its screen.

## Phases

- [ ] **0. Set up.** `git pull --rebase --autostash`. Install Flutter 3.47.5 to
  `/home/user/tools/flutter` if missing (releases_linux.json →
  storage.googleapis.com), `flutter pub get`. Inter for renders:
  `/usr/share/fonts/opentype/inter` symlinked as `.ttf` (SIDEKICK_FONTS).
- [ ] **1. One look.** `ui/app_theme.dart` becomes the 4.0 tokens (dark only,
  Inter / system font, pill buttons, 22 px cards, no shadows). Remove
  `nothing.dart`, `nothing_screens.dart`, `glass.dart`, `theme_maker.dart`,
  `core/custom_theme.dart`, their tests and screenshot renders, the Theme
  dropdown and alternate Nothing icons; old prefs (`look`, `customTheme`,
  `themeColor`) are ignored. Keep `contrast_test` passing for the one theme.
- [ ] **2. Shell.** Phone: the floating rounded dock (Devices · Chat · Send ·
  Remote · Settings; selected = white pill with icon + name). Computer: rail
  (sk icon, Devices, Files, Remote, Settings) + a 300 px column + the main
  panel, as in the emulator's `pcRender`. Tablets get the computer layout.
- [ ] **3. Chat.** `core/history.dart`: a per-device list of what was sent and
  received (files, photos, links, notes, requests), saved to a JSON file in
  the app's data folder, capped (e.g. 500 per device). AppState records into
  it on every send/receive. Chat screen: device picker, filter chips (All,
  Files, Photos, Links, Notes), search, item cards (file: Open / Show in
  folder; photos: thumbnails; link: Open link; note; code: big digits + Copy
  code), hold (or right-click) a card → actions sheet (Open, Copy, Show in
  folder, Send again, Remove from this list) closed by ✕ or flick down, the
  message bar (+, field, Send files that becomes a round Send while typing).
  Receiving shows the "Receiving files" card with a bar in the chat.
- [ ] **4. Devices + Connect.** Needs you (amber card), Favorites, Paired,
  Nearby (dashed), first-launch empty state; Connect sheet: Nearby / QR code /
  Code (the existing pairing logic underneath).
- [ ] **5. Send, Sending, Accept.** Send tab: tiles (Files, Photos & videos,
  Text or link, Paste), the selection card, Send to (devices with Send
  pills). Sending screen: the ring (eased), per-file bars, Stop, Back keeps it
  going. Accept: the amber request sheet (phone) / dialog (computer) with
  file list, "Always accept from …", Decline / Accept. Corner pop-up and tray
  panel restyled to the tokens.
- [ ] **6. Remote + Settings.** Remote: device picker card, touchpad (dot
  under the finger), Left / Right click / Keyboard, Shortcuts per platform.
  Settings in the emulator's layout, plus **App icon** (8 icons; Dusk
  default): `make_icons.py` makes each set from `design/logo-sk/*.png`;
  `AppIcon.apply` gets one alternate per icon (iOS alternate icons, Android
  activity-aliases, Mac Dock icon, Windows window icon).
- [ ] **7. Notices and errors.** Notices one at a time (the next waits; the
  one showing leaves 3 s later), swipe down or ✕; errors as the emulator's
  pop-up. No badges anywhere.
- [ ] **8. Verification codes only.** `NotificationRelay` /
  `_relayNotification` send only a 6-digit code and the app's name; the
  computer shows "Copy code 482913"; the setting's wording and both privacy
  policies (privacy.html, app/packaging/privacy.txt) say so.
- [ ] **9. Motion pass.** Springy presses everywhere, entrance cascades,
  sheets that follow the finger, eased progress, Hero card → screen,
  reduced-motion respected inside the app.
- [ ] **10. Check and release.** Update and run `tool/screenshots_test.dart`,
  `transfer_shots_test.dart`, `sizes_test.dart` (no overflow at any size);
  compare with the emulator shots; fix differences. Version 4.0.0+400 in
  pubspec. Push, wait for CI green on all four platforms, run the `Build`
  workflow with `release_tag: v4.0.0`, add 4.0.0 to VERSIONS.md, update
  CLAUDE.md (remove the Nothing / Liquid Glass / Make theme sections; describe
  4.0), and send the owner the screenshots (phone and computer, every tab).
